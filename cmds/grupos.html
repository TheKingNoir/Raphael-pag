👥 Grupos

Comandos de Grupo para administrar y moderar.

alerts_<on|off>_

Activar o desactivar las alertas del grupo.

Alias: alerts, alertas
antilinks_<on|off>_

Activar o desactivar el anti-enlaces.

Alias: antilink, antilinks, antienlaces
antistatus_<on|off>_

Activar o desactivar el anti-estados.

Alias: antistatus, antiestados
bot_<on|off>_

Activar o desactivar el bot en el grupo.

Alias: bot
economy_<on|off>_

Activar o desactivar los comandos de economía.

Alias: economy, economia
gacha_<on|off>_

Activar o desactivar los comandos de gacha.

Alias: gacha, rpg
nsfw_<on|off>_

Activar o desactivar los comandos NSFW.

Alias: nsfw
adminonly_<on|off>_

Permitir que solo los admins puedan usar los comandos.

Alias: adminonly, onlyadmin
welcome_<on|off>_

Activar o desactivar la bienvenida.

Alias: welcome, bienvenida
goodbye_<on|off>_

Activar o desactivar la despedida.

Alias: goodbye, despedida
setwelcome_<value>_

Establecer un mensaje de bienvenida personalizado.

Alias: setwelcome
setgoodbye_<value>_

Establecer un mensaje de despedida personalizado.

Alias: setgoodbye
close_<time>_

Cerrar el grupo para que solo los admins puedan enviar mensajes.

Alias: close, cerrar
open_<time>_

Abrir el grupo para que todos puedan enviar mensajes.

Alias: open, abrir
groupinfo

Ver la información del grupo.

Alias: gp, groupinfo
setgpbanner_<cite / image>_

Cambiar la imagen del grupo.

Alias: setgpbanner
setgpname_<value>_

Cambiar el nombre del grupo.

Alias: setgpname
setgpdesc_<value>_

Cambiar la descripción del grupo.

Alias: setgpdesc
setgpstatus_<text|cite> ..._

Publicar un estado en el grupo.

Alias: setgpstatus
kick_<mention|función>_

Expulsar a un usuario del grupo.

Alias: kick, ban, bang
promote_<mention>_

Ascender a un usuario a administrador.

Alias: promote, promover
demote_<mention>_

Descender a un usuario de administrador.

Alias: demote, degradar
warn_<mention / reason>_

Darle una advertencia a un miembro del grupo.

Alias: warn
warns_<mention>_

Ver todas las advertencias de un miembro del grupo.

Alias: warns
delwarn_<mention / number|all>_

Eliminar una advertencia de un miembro del grupo.

Alias: delwarn
setwarnlimit_<number>_

Establecer el límite de advertencias del grupo.

Alias: setwarnlimit
tag_<text>_

Mencionar a todos los usuarios del grupo.

Alias: hidetag, tag, tagall, todos
link

Obtener el enlace del grupo.

Alias: link
revoke

Restablecer el enlace del grupo.

Alias: revoke, restablecer
msgcount_<mention / days>_

Obtener el conteo de mensajes de un usuario.

Alias: count, mensajes, messages, msgcount
topcount_<days>_

Ver el top de usuarios con más mensajes en el grupo.

Alias: topcount, topmensajes, topmsgcount, topmessages
topinactive_<days>_

Ver el top de usuarios más inactivos del grupo.

Alias: topinactive, topinactivos, topinactiveusers
