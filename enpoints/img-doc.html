🖼️ Documentación API ARCANE IMG

Guía de integración para el buscador de imágenes.

GET Verificar estado de la API 📊
https://bimg-api.raphaelbot.com/health

Ejemplo de resultado:

{
  "status": "OK",
  "message": "API de bimage-scraper funcionando"
}
GET Buscar imágenes 🔎
https://bimg-api.raphaelbot.com/search?query=[TEXTO]&limit=[NÚMERO]

Headers requeridos:

x-api-key: [TU_API_KEY]
  • [TEXTO] = Lo que quieres buscar (Ej: Gatos)
  • [NÚMERO] = Cantidad de imágenes (Ej: 5)
  • [TU_API_KEY] = Tu clave secreta (Ej: 8affc894-...)

Ejemplo de resultado:

{
  "success": true,
  "count": 5,
  "results": [
    {
      "title": "Título de la imagen",
      "image": "https://.../imagen.jpg",
      "thumbnail": "https://.../imagen-mini.jpg",
      "source": "https://.../pagina-origen.com"
    }
  ]
}
GET Descargar imágenes 📥
https://bimg-api.raphaelbot.com/download?url=[URL_IMAGEN]

Headers requeridos:

x-api-key: [TU_API_KEY]
  • [URL_IMAGEN] = La URL de la imagen que quieres descargar

Ejemplo de resultado:

El archivo de la imagen (descarga directa)
GET Buscar y descargar en un mismo endpoint 🌐
https://bimg-api.raphaelbot.com/search?query=[TEXTO]&limit=[NÚMERO]&download=true

Headers requeridos:

x-api-key: [TU_API_KEY]
